# Inner Compass

MBTI 인지기능과 에니어그램을 생애 시간축과 함께 탐색하는 단일 파일 정적 웹앱입니다.

## 배포

### GitHub Pages
1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 루트에 업로드합니다.
3. 저장소 Settings → Pages에서 배포 소스를 해당 브랜치의 루트(`/`)로 선택합니다.
4. 생성된 Pages 주소를 공유합니다.

### Netlify
Netlify의 새 사이트 생성 화면에서 이 폴더 전체를 정적 사이트로 배포하면 됩니다. 별도 빌드 명령은 필요하지 않습니다.

## 개인정보
- 외부 라이브러리/분석 스크립트 없음
- 서버 통신 없음
- 진행상황은 사용자가 검사 중일 때 브라우저 `localStorage`에만 임시 저장
- 결과 계산 후 저장값 자동 삭제

## 주요 특징
- MBTI 인지기능(Ni/Ne/Si/Se/Ti/Te/Fi/Fe) 문항 추가
- 오래된 자동반응과 현재 행동을 별도 응답
- 주기능/부기능/3차기능/열등기능 후보 추정
- wing을 과거 우세 / 현재 우세 / 생애 전체 가설로 분리
- 본능 스택도 과거 우선순위 / 현재 생활전략 분리
- 변화 요인(훈련, 실패/소진, 역할, 관계, 가치관, 자기조절) 자기보고 섹션 추가
- 다른 검사 결과를 직접 유형에 매핑하지 않는다는 안내 추가

## 주의
이 도구는 비임상 자기탐색용 휴리스틱입니다. MBTI 인지기능론, 에니어그램, wing, trifix/tritype, 본능 스택은 임상 진단 도구가 아닙니다.
